# Histórico do redesign

Cada versão é uma cópia completa de `conceitos/` como estava naquele momento, e também um commit com tag no git
(`git checkout <versão>` volta o projeto inteiro). Para abrir uma versão no navegador:
`http://<ip-do-mac>:8080/historico/<versão>/` (ou localhost).

Para salvar uma nova versão: `historico/salvar.sh <versão> "descrição"`.

As versões 1 e 2 (os cinco conceitos originais e a primeira troca em tela cheia) não foram guardadas na hora;
a v3 é o primeiro registro fiel.
